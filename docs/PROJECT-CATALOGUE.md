## Maturity rules

Alpha means incomplete implementation/integration; beta candidate means suitable to assess for controlled user testing, not a certified beta release. RC requires frozen scope and validated release artifacts. RTM/stable requires qualified delivery, installation, upgrade/rollback and support evidence. **No independently maintained program has been qualified RC or RTM by this review.** OpenCode has a published development release, not an RTM designation. Completion percentages remain unknown without agreed acceptance checklists.
